# Jasper Kim / 김동현

회화·연기와 현재 브랜드를 모으는 개인 포트폴리오입니다.

Cloudflare Pages: `main`, 프레임워크 없음, 빌드 명령 비움,
출력 디렉터리 `dist`, 루트 디렉터리 비움.

작품 사진과 영상은 사용자 제공 자료의 웹용 사본입니다.
원본 파일, 개인 맥락 문서와 수집 기록은 공개 저장소에 포함하지 않습니다.
일부 Instagram 자료는 수집 중입니다. 신청 폼의 API는 FEEDBACK_DB와 소유자 인증을 재사용합니다. 배포 전 applications/schema.sql을 D1에 적용하세요.
